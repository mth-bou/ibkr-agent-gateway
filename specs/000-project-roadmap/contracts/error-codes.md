# Contract: Stable Error Codes

This roadmap-level catalog defines families. Individual feature specs may add feature-specific codes but must not reuse a code with a different meaning.

## Config

- `CONFIG_INVALID`
- `CONFIG_MISSING_BROKER_BASE_URL`
- `CONFIG_TLS_BYPASS_NON_LOCALHOST`
- `CONFIG_SECRET_MISSING`
- `CONFIG_FEATURE_DISABLED`
